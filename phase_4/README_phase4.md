# Phase 4 - The website

4A_data_builder   a Colab notebook that turns the results of Phase 3 and the Global Wind Atlas rasters into the data files of the website.
4B_website        the website itself (Leaflet map, GitHub Pages) + screenshots of the three development steps.

Website features (tested by you in the browser): wind layer for all Azerbaijan at 50/100/150 m with opacity and click readout,
study region, 10 turbines of the best compromise with tower-height colours and a "why here" text (AZ/EN), access points,
indicative connection lines, 91 Pareto solutions with scatter plot, presets, table and CSV/GeoJSON downloads, disabled "Scenarios" section.

What is missing in this folder (add by hand): the final site/ folder, the country GeoTIFF files and data.zip (see the txt files).
